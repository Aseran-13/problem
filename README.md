# Standalone Static Portfolio & Builder

A pure static personal portfolio engineered strictly with:
- **HTML5**
- **CSS3**
- **Vanilla JavaScript**

**Zero dependencies. No frameworks. No build step. No backend.**

Directly deployable to **GitHub Pages** or openable by double-clicking `index.html` in your browser.

---

## 📁 Repository Structure

```
/
├── index.html          # Standalone public portfolio (Deploy this)
├── customize.html      # Portfolio builder & editor (Generates index.html)
├── assets/
│   ├── icons/          # SVG icons (checkmark, arrow, linkedin, github, email, etc.)
│   ├── images/         # Profile and project graphics
│   └── documents/      # Downloadable resume
├── README.md           # Instructions
└── .gitignore
```

---

## 🚀 How to Customize & Generate `index.html`

1. Open `customize.html` in any web browser.
2. Edit your profile info, bio, experience, skills, projects, and contact channels.
3. Review your edits in real-time in the split-screen preview (Desktop, Tablet, or Mobile).
4. Click **🚀 Generate index.html**.
5. Save or replace the `index.html` file in your repository.
6. Push to GitHub — GitHub Pages immediately serves your updated portfolio!

---

## 🌐 Deploying to GitHub Pages

1. Push this repository to GitHub.
2. In your repository on GitHub, navigate to **Settings** → **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Your portfolio is live at `https://<username>.github.io/<repository-name>/`.
